# 삼도식당 1화 장면 구성 Best-of-5 v0.1

상태: `구조 탐색 후보 / 대본 아님 / 미승인`

목적: 같은 설정과 같은 결말을 유지한 채 장면의 입장 순서와 중심 압력을 달리한 다섯 안을 비교한다. 기존 0.4 대본은 보존한다.

## 고정 사실

- 식당은 이미 오래 영업 중이다.
- 도윤과 연화는 서로 반말하는 공동 운영자다. 도윤은 손님에게만 존댓말한다.
- 도윤은 첫 장면부터 완성형 셰프이며 조리에 실패하지 않는다.
- 연화는 발랄하지만 방해꾼이 아니다. 손님의 변화와 저승의 운영 신호를 먼저 읽는다.
- 김문성은 불과 기계를 오래 다룬 흔적이 있는 손님이다.
- 첫 망각어 맑은국과 별도 불향 국물은 모두 처음부터 완성품이다.
- 김문성은 자기 끝맛을 고르고 한 그릇을 더 주문한 뒤 결제하고 퇴장한다.
- 4분 35초 안에 끝나며 사고, 현실의 딸, 계약, 개업 과정은 설명하지 않는다.

## 비교 방식

총점을 합산하지 않는다. 다음 질문으로 두 안씩 맞붙인다.

1. 《이세계 식당》처럼 이미 검증된 식당의 안정감이 먼저 생기는가.
2. 도윤의 실력이 묘기가 아니라 반복 가능한 영업 능력으로 보이는가.
3. 연화의 발랄함과 운영 권한이 동시에 보이는가.
4. 음식이 조리, 향, 첫입, 구성 요소, 완식으로 충분히 머무는가.
5. 손님의 식후 행동과 식당에 남는 흔적이 한 인과로 이어지는가.

하나라도 크게 무너지면 다른 항목의 장점으로 상쇄하지 않는다.

## 후보 1. 단골의 정해진 주문

핵심 가설: 관객에게는 첫 만남이지만 도윤과 연화에게 김문성은 이미 몇 번 온 손님이다. 반복 주문이 식당과 셰프의 실력을 먼저 증명한다.

주 레퍼런스 기능: 《이세계 식당》 1화 붉은 여왕 구간의 반복 욕망과 확정 주문.

| 시간 | 장면 구성 |
| ---: | --- |
| 0:00~0:18 | 도윤은 이미 육수를 보고 있고 연화는 영업 목패와 지난 주문표를 정리한다. 연화가 뚜껑을 열려 하자 도윤이 보지도 않고 막는다. 둘은 반말로 짧게 받아친다. |
| 0:18~0:43 | 김문성이 들어온다. 연화가 `오늘도 뜨거운 걸로?`라고 묻는다. 김문성은 늘 그랬듯 따뜻하면 된다고 답한다. 도윤은 이미 망각어를 꺼낸다. |
| 0:43~1:05 | 도윤이 오늘 망각어 상태가 좋다고 알리고 맑은국을 확정한다. 손과 표찰, 화덕을 보는 시선이 현재 물증으로 놓인다. |
| 1:05~2:35 | 90초 조리. 맑은 육수와 불향 육수를 함께 준비한다. 연화는 장난스럽게 맛보기를 노리다가 김문성의 불 시선을 읽고 검은 주전자를 맡는다. |
| 2:35~3:30 | 접시, 김, 향, 첫 숟갈, 뿌리, 생선살, 완식 순서로 첫 그릇을 지급한다. 대사를 줄이고 먹는 행동을 버틴다. |
| 3:30~4:08 | 김문성이 불향 끝맛을 고른다. 두 번째 그릇을 맛본 뒤 처음으로 취향을 명확히 말한다. |
| 4:08~4:27 | `한 그릇 더.` 추가 주문, 완식의 압축 몽타주, 결제, 기관실 표찰의 위치 변화. 새 주문 목패가 남는다. |
| 4:27~4:35 | 연화가 자기 직원식을 요구하고 도윤이 이미 준비한 접시를 민다. 둘은 반말로 끝낸다. |

강점:

- 단골 한 명만으로 사회적 증거, 셰프 권위, 감정 변화를 동시에 처리한다.
- 도윤이 손님을 진단하거나 시험하지 않아도 된다.
- 연화와 도윤이 김문성의 습관을 함께 아는 공동 운영자로 보인다.
- 현재 설정을 거의 바꾸지 않고 《이세계 식당》의 안정감을 가장 강하게 가져온다.

위험:

- 김문성이 왜 이미 단골인지 설명하려 들면 5분이 무너진다. 대사 한 줄과 주문표만으로 끝내야 한다.
- 추가 한 그릇을 전부 먹는 시간을 길게 주기 어렵다. 첫 그릇을 본식, 두 번째를 끝맛과 재주문 증거로 구분해야 한다.

## 후보 2. 빈 그릇이 증명하는 식당

핵심 가설: 김문성은 처음 온 손님으로 유지한다. 대신 손님이 들어오기 전 빈 그릇, 결제 동전, 반복 주문 목패가 식당의 인기를 증명한다.

주 레퍼런스 기능: 《이세계 식당》의 단골 군상을 인물 추가 없이 사물로 압축한다.

| 시간 | 장면 구성 |
| ---: | --- |
| 0:00~0:28 | 서로 다른 세 개의 빈 그릇과 결제 흔적. 연화가 주문 목패를 큰 소리로 읽으며 정리하고, 도윤은 다음 육수를 보충한다. 어떤 손님들이 무엇을 반복 주문하는지 사물로 보여 준다. |
| 0:28~0:50 | 김문성이 처음 들어온다. 식당의 익숙한 리듬과 달리 문 앞에서 멈춘다. 연화가 자리를 만들고 주문 목패를 든다. |
| 0:50~1:15 | 따뜻한 음식이면 된다는 수동적 주문. 도윤이 좋은 망각어를 권한다. 연화는 주문을 확정한다. |
| 1:15~2:35 | 80초 조리. 도윤의 손과 불, 연화의 검은 주전자 판단. |
| 2:35~3:35 | 첫 그릇의 향, 첫입, 구성 요소, 완식. 기존 단골들의 빈 그릇과 김문성의 빈 그릇이 같은 선반에 놓인다. |
| 3:35~4:15 | 불향 끝맛 선택과 추가 주문. 김문성이 처음으로 다른 단골처럼 자기 주문을 갖는다. |
| 4:15~4:35 | 결제와 주문 목패. 연화가 김문성의 목패를 기존 반복 주문들 사이에 건다. 도윤과 연화의 직원식 코다. |

강점:

- 추가 캐릭터 없이 식당의 역사와 인기를 강하게 보여 준다.
- 김문성이 `주문이 없는 사람 → 자기 주문을 가진 단골 후보`로 바뀌는 결말이 선명하다.
- 주문 목패가 감정과 운영 흔적을 동시에 담당한다.

위험:

- 오프닝 사물 몽타주가 길어지면 도윤과 연화의 첫인상이 늦어진다.
- 조리 시간이 80초로 줄어 음식 중심 작품의 만족도가 후보 1보다 낮다.

## 후보 3. 문턱에서 시작하는 손님

핵심 가설: 김문성의 망설임을 식당 밖에서 먼저 보여 준다. 연화가 문을 열어 그를 식당의 질서 안으로 들이고, 도윤이 음식으로 자리를 확정한다.

주 레퍼런스 기능: 《이세계 식당》의 외부인 편입과 안전한 식탁.

| 시간 | 장면 구성 |
| ---: | --- |
| 0:00~0:25 | 안개 속에서 김문성이 문손잡이를 잡지 못한다. 안에서는 도윤의 칼과 냄비 소리가 들린다. 연화가 문을 벌컥 열고 `들어올 거면 들어와`라며 자리를 내준다. |
| 0:25~0:50 | 식당 안의 익숙한 영업 풍경. 연화는 빠르게 물과 목패를 놓고, 도윤은 손님을 흘끗 본 뒤 망각어를 꺼낸다. |
| 0:50~1:10 | 따뜻한 것이면 된다는 주문과 망각어 추천. 김문성의 손과 표찰을 짧게 보여 준다. |
| 1:10~2:40 | 90초 조리. 연화는 홀과 주방 사이를 오가며 발랄함과 서비스 권한을 보여 준다. |
| 2:40~3:35 | 첫 그릇을 천천히 먹는다. 김문성의 몸이 문 쪽에서 식탁 쪽으로 기울어지는 변화를 강조한다. |
| 3:35~4:15 | 불향 선택과 추가 주문. 처음에 문손잡이를 놓지 못했던 손이 주문 목패를 직접 밀어준다. |

- 연화가 손님을 식당 질서로 편입시키는 실무 권한을 갖는다.
- 감정적 페이오프가 기관실 표찰보다 단순한 몸의 행동으로 읽힌다.

위험:

- 도윤이 첫 25초 동안 소리로만 존재해 주인공성 지급이 늦다.
- 처음 온 외부인 구조라 《이세계 식당》 전반부보다 아렛타 구간의 인상이 강해진다.

- 음식 중심은 강하지만 《이세계 식당》의 단골 사회와 운영 권위는 약하다.

## 쌍대 비교

### 1차: 후보 4 대 후보 5

후보 4는 도윤과 음식을, 후보 5는 두 주연의 상품성을 빠르게 판다. 둘 다 한쪽이 늦는다. 현재 목표는 《이세계 식당》의 안정된 식당과 두 주연을 함께 세우는 것이므로 어느 쪽도 대표안으로 올리지 않는다.

- 후보 4 탈락 사유: 손님과 연화의 판단이 늦다.
- 후보 5 탈락 사유: 활극과 티키타카가 식당의 반복 욕망을 덮는다.

### 2차: 후보 2 대 후보 3

후보 2는 식당의 역사를, 후보 3은 한 손님의 감정 변화를 더 잘 보여 준다. 파일럿에서는 고정 무대의 검증이 먼저다. 후보 2를 올린다.

- 후보 3 보류 사유: 도윤의 첫 지급이 늦고 외부인 구호 서사가 강하다.
- 후보 2 승리 사유: 추가 인물 없이 사회적 증거와 주문 잔여물을 한 화면에 묶는다.

### 결승: 후보 1 대 후보 2

후보 2는 김문성이 처음 자기 주문을 얻는 변화가 선명하다. 후보 1은 한 명의 단골만으로 식당의 역사, 도윤의 예측 가능한 실력, 연화의 친숙한 접객, 손님의 작은 변화를 모두 처리한다. 장면 수와 설명 부담도 더 적다.

대표안은 **후보 1 `단골의 정해진 주문`**이다.

후보 2에서 가져올 것은 오프닝 한 컷뿐이다. 지난 주문 목패 두세 개를 배경에 걸어 다른 단골의 존재를 암시한다. 별도의 빈 그릇 몽타주나 단골 설명은 추가하지 않는다.

## Best-of-5 판정

1. 대표안: 후보 1 `단골의 정해진 주문`
2. 보조 요소: 후보 2의 지난 주문 목패 한 컷
3. 감정 동작 대안: 후보 3의 `문손잡이를 잡는 손`은 기관실 표찰보다 명확한 결말이 필요할 때만 교체 검토
4. 탈락: 후보 4, 후보 5

이 판정은 대본 승격이나 HIL 3 책임자 승인이 아니다. 다음 작업은 후보 1만 인간용 대본으로 내려 쓰고, 다른 네 안의 대사를 섞지 않는 것이다.
