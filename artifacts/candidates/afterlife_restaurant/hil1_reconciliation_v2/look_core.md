# 룩코어 — 지정 구글 드라이브 코퍼스 기준

## 권위와 사용 범위

- 시각 기준 코퍼스: 사용자가 지정한 `오리지널IP-요리애니` 구글 드라이브 폴더.
- 이 문서는 드라이브 에셋을 **제작 룩 참조**로 연결한다. 대본 사실이나 서사 설정을 이미지 파일명만으로 확정하지 않는다.
- 외부 이미지·웹 레퍼런스를 새 룩 기준으로 섞지 않는다. 권리·출처는 이 패키지에서 추정하지 않는다.

## 제작 체크

1. 콘티·이미지 프롬프트마다 `style plate + character sheet variant + episode`를 적는다.
2. 새 장소·조연·소품은 지정 폴더의 `이미지` 코퍼스를 먼저 확인한 뒤, 확인된 자료만 룩 기준으로 승격한다.
3. 전체 화풍판과 캐릭터 시트에서 확인하지 못한 색·체형·의상 디테일은 ‘추정’으로 고정하지 말고 제작 전 선택안을 남긴다.
4. 산출물 공개·업로드 전에는 코퍼스 사용 권한과 선택한 원본 에셋을 별도로 확인한다.
