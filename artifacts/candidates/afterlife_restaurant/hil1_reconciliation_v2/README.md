# 저승식당 HIL 1 정합 패키지 v2

- 상태: `candidate / owner_review_required`
- 잠금 정합: `hash_reconciliation_required`
- 외부 공개·승격: 금지
- 대본 변경: 없음
- 기준: 잠금된 제1~9화 대본과 소유자 제공 핵심 설정만 사용

이 패키지는 예전 승인 HIL 1을 덮어쓰지 않는다. 현재 잠금본과 맞지 않는 과거 기획을 대신해, 다음 작업이 참조할 **후보 정합본**을 만든 것이다.

구성은 다음과 같다.

- `synopsis.md`: 현재 1~9화 서사 요약
- `character_sheet.md`: 대본 확정 사실과 비공개 핵심 설정을 분리한 캐릭터 시트
- `arc_map.md`: 회차별 사건과 독자가 소비하는 주요 정서를 묶은 아크 맵
- `look_core.md`: 지정 구글 드라이브 코퍼스를 기준으로 한 룩코어 참조 규칙
- `canonical_planning_v2.md`: 5화 이상 대본에서 시놉시스를 갱신하는 캐노니컬 절차
- `source_lock.md`: 이번 정합의 입력 잠금본과 해시

원고를 고치려면 먼저 해당 회차를 재개방하고 새 해시를 만든 뒤, 이 패키지를 다시 생성한다. 반대로 이 패키지를 수정한다고 원고가 바뀌지는 않는다.

현재 파일의 SHA-256은 기존 잠금 기준 문서에 기록된 값과 일치하지 않는다. 이번 패키지는 **현행 1~9 파일을 읽기 전용 입력으로 삼은 후보본**이며, 기존 잠금 문서의 해시 갱신·승격은 포함하지 않는다.
